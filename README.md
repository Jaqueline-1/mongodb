# Banco de Dados — SQL e MongoDB

Projeto desenvolvido durante o **Módulo 19 do curso de Qualidade de Software da EBAC**, com foco na prática de consultas em bancos de dados SQL e NoSQL.

## 📚 Conteúdo praticado

### SQL
- Criação de tabela
- Inserção de dados
- Consultas com `SELECT`
- Filtros com `WHERE`
- Ordenação com `ORDER BY`
- Consultas por nota, curso e nome

### MongoDB
- Criação e utilização de banco de dados
- Inserção de documentos com `insertMany()`
- Consultas com `find()`
- Ordenação com `sort()`
- Filtros por campos
- Operadores `$gte`, `$and` e `$in`
- Manipulação de documentos JSON

## 🛠️ Tecnologias utilizadas

- MongoDB
- MongoDB Compass
- Docker
- SQLite
- DBeaver
- Visual Studio Code
- Git e GitHub
